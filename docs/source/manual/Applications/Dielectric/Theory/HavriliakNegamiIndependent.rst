--------------------------------------------------------
Havriliak-Negami modes (independent times)
--------------------------------------------------------

.. automodule:: RepTate.theories.TheoryHavriliakNegamiModesIndependent.TheoryHavriliakNegamiModesIndependent

Description
-----------

This theory fits independent Havriliak-Negami modes:

.. math::

    \epsilon^*(\omega) = \epsilon_\infty + \sum_i
        \frac{\Delta\epsilon_i}
        {\left[1+(i\omega\tau_i)^\alpha\right]^\gamma}.

Each mode has an independent relaxation time :math:`\tau_i` and strength
:math:`\Delta\epsilon_i`. The asymmetry :math:`\alpha` and broadness
:math:`\gamma` parameters are common to all modes. The mode toolbar provides
independent dragging, loading, saving, deletion, and conservative
simplification of the spectrum.

The theory is available as
``Havriliak-Negami modes (independent)``.
